01

AI-Powered Incident Response & SRE Platform

I built this to watch a production-style service running at around 450 requests a second and catch problems before they turn into real outages. When something breaks, it traces back through Git history to find the commit that likely caused it, pulls the relevant runbook with RAG, and writes up a Slack report so whoever's on call isn't starting from zero. I also built a human-in-the-loop rollback flow and tested it against four different failure scenarios (Python, FastAPI, React, LiteLLM, ChromaDB).

Python · FastAPI · React · LiteLLM · ChromaDB · RAG

02

Oculon: Smart Traffic Monitoring & Alert System

Oculon pulls in 12 live camera feeds from four state DOT networks and flags likely collisions by matching what's on screen against frame-level motion data. When it catches something, it sends an alert to Discord, with a Twilio SMS backup in case Discord's down. Most of the debugging time went into cross-browser video playback (hls.js was the culprit) before I shipped it as one Vercel deployment.

React · Vite · Tailwind · Flask · Twilio · hls.js

03

End-to-End Data Engineering & MLOps Pipeline

I set up a governed data lake on AWS S3, with Glue handling the ETL and Lake Formation controlling access, then extended it into Databricks with a bronze-silver-gold Delta Lake pipeline in PySpark to clean up raw Census data. From there I trained a PyTorch model to predict state-level population growth and used MLflow to keep track of runs as I iterated.
