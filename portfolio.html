AI-Powered Incident Response & SRE Platform

Built an autonomous AI platform (Python, FastAPI, React, LiteLLM, ChromaDB) that continuously monitors a production-style web service under ~450 requests/sec, automatically detecting software failures and performing root cause analysis to identify faulty Git commits. Smart Traffic Monitoring and Alert System (Oculon)

Built Oculon (React, Vite, Tailwind, Flask, Twilio), a dashboard aggregating 12 live HLS feeds from 4 state DOT camera networks that flags collisions by matching playback position to incident windows derived from frame-level motion analysis. Engineered a pluggable alert pipeline dispatching incident reports to Discord with Twilio SMS fallback, fixed cross-browser playback with hls.js, and shipped the app as one Vercel serverless deployment.
